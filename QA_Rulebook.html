Curriculum Restructure QA Rulebook v1.0

Status: Locked after calibration through Modules 1 and 2.

1. Purpose

Validate that curriculum restructuring has not introduced inconsistencies, broken navigation, stale references, metadata defects, or architectural regressions. This is not a content review.

2. Scope

  • Curriculum integrity
  • Navigation integrity
  • Metadata integrity
  • Terminology consistency
  • Website structural consistency

3. Out of Scope

  • Grammar and writing style
  • Technical depth
  • Examples or analogies
  • Content expansion or reduction
  • Editorial opinions
  • UI/UX redesign
  • SEO strategy (except metadata integrity)

4. Review Workflow

  1. Read the module change report first.
  2. Read every section completely.
  3. Validate every change point.
  4. Run the full QA checklist.
  5. Issue a binary verdict: PASS or FAILED.

5. QA Checklist

#CategoryValidation
1Change ReportEvery numbered point implemented.
2Narrative ContinuityOpening/closing transitions, forward & backward references.
3Curriculum ContinuityCorrect module, section and category references.
4Completed-Site RuleTreat placeholders as real neighbours; no skipped sections.
5Canonical Topic LinkingFirst mention links to canonical destination.
6Internal NavigationCards, buttons, links, anchors and paths resolve correctly.
7External ResourcesOfficial Adobe resources only; no broken or operational links.
8Metadata Integrityslug, title, seotitle, description, type, module/section, weight, lastmod.
9TerminologyConsistent names across prose, tables, diagrams and cards.
10Component IntegrityCallouts, path boxes, reference boxes, tables and paragraphs structurally correct.
11Topic OwnershipConcepts belong to the correct module after restructuring.
12Category OwnershipNo obsolete curriculum groupings remain.
13Diagram ConsistencyDiagram labels and flow match surrounding content.

6. PASS / FAIL Criteria

PASS: Every change point verified and no restructuring defects found.

FAILED: Any verified restructuring defect exists. One confirmed defect is sufficient.

Guiding Principle
A module passes only when it behaves as though it were part of the final completed website. Every page must integrate correctly into the curriculum, regardless of whether neighbouring sections are already written.
