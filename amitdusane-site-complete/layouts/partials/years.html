{{- /* =========================================================================== YEARS OF EXPERIENCE, COMPUTED. One source of truth: params.careerStart. The figure used to be typed as "16 years" in five places and spelled out as "sixteen years" in two more, which meant seven edits every February and a near-certainty that one of them would be missed. It is now derived here and nowhere else. EXACT, NOT APPROXIMATE. Dividing elapsed seconds by 365.25 days is the obvious way and it is wrong by up to a day either side of the anniversary, so the site would tick over early or late. This subtracts calendar years and then takes one back if the anniversary has not arrived yet, which is how a person actually counts. Call it plain for a digit, or with `words` for the spelled-out form: {{ partial "years.html" . }} -> 16 {{ partial "years.html" (dict "ctx" . "words" true) }} -> sixteen IT UPDATES AT BUILD TIME, not when somebody loads the page. Every push to main rebuilds, so it corrects itself the next time anything ships. If the site ever goes quiet across a February, a scheduled rebuild in the deploy workflow is what would keep it honest. =========================================================================== */ -}} {{- $ctx := . -}} {{- $words := false -}} {{- if reflect.IsMap . -}} {{- $ctx = .ctx -}} {{- $words = default false .words -}} {{- end -}} {{- $start := time.AsTime (default "2010-02-02" $ctx.Site.Params.careerStart) -}} {{- $now := now -}} {{- $y := sub $now.Year $start.Year -}} {{- if or (lt (int $now.Month) (int $start.Month)) (and (eq (int $now.Month) (int $start.Month)) (lt $now.Day $start.Day)) -}} {{- $y = sub $y 1 -}} {{- end -}} {{- if $words -}} {{- /* Covers 10 to 40, which is the whole plausible life of this site.
