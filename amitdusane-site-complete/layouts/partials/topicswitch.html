{{- /* =========================================================================== THE TOPIC SWITCHER. Created 12 September 2026. One button that opens every topic in the section, grouped, with the current one marked, and the glossary at its foot. IT REPLACES TWO THINGS: the persistent left rail, and "See where this fits". Amit's call, the same day, and the reasoning is the count. Twelve topics is a thing a reader can hold in their head, so a picker they open when they want it beats a column that is on screen always -- and the column, at the learning world's own measurements, was one of the reasons readers could not tell a Basics section from the curriculum. wherefits.html is untouched and stays the learning world's; it is simply no longer rendered for a Basics topic. THE GLOSSARY SITS AT THE FOOT because the rail used to carry it. Without that, the lookup page would be reachable only from the section front page, which is a route nobody takes mid-sentence. The count is COUNTED from the topics' own words, never typed, so it cannot drift. =========================================================================== */ -}} {{ $w := index .Site.Params.worlds .Section }} {{ $topics := (where (where .Site.RegularPages "Section" .Section) "Type" "topic").ByWeight }} {{ $groups := slice }} {{ range $k, $v := $w.groups }}{{ $groups = $groups | append (merge $v (dict "key" $k)) }}{{ end }} {{ $groups = sort $groups "order" }} {{ $nw := 0 }}{{ range $topics }}{{ $nw = add $nw (len .Params.words) }}{{ end }}
{{ range $g := $groups }}{{ with where $topics "Params.group" $g.key }}
{{ $g.label }}
{{ range . }}{{ .LinkTitle | default .Title }}{{ end }}
{{ end }}{{ end }} {{ with .Site.GetPage (printf "%s/glossary" $w.root) }} Glossary{{ $nw }} words {{ end }}
