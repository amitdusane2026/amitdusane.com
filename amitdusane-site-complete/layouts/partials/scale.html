{{- /* How big is this, before you start. A landing page's job is to tell a reader where to go; this tells them what it costs to go there, which is the question a learner actually has and which nothing on the site answered. Modules run from 4,882 to 26,691 words and that difference matters to somebody deciding whether to begin. Counts WRITTEN sections only, using the `description` publish flag, the same switch that dims an unwritten section in the maps. Counting stubs would report a module of four sections and twenty-four words. A landing whose sections are all unwritten shows nothing at all rather than a zero. */ -}} {{- $p := .page -}} {{- $pages := where $p.RegularPagesRecursive "Description" "!=" "" -}} {{- $n := len $pages -}} {{- if gt $n 0 -}} {{- $words := 0 -}} {{- range $pages -}}{{- $words = add $words (countwords .Content) -}}{{- end -}} {{- $mins := int (math.Round (div (float $words) 220)) -}} {{- $time := printf "about %d min" $mins -}} {{- if ge $mins 60 -}} {{- $h := div $mins 60 -}}{{- $m := mod $mins 60 -}} {{- $time = cond (eq $m 0) (printf "about %d hr" $h) (printf "about %d hr %d min" $h $m) -}} {{- end -}}
