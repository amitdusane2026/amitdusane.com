A browser gives you a network tab. An app gives you nothing, and that absence is the biggest practical difference between web and mobile work.

Assurance fills it. It connects to a running app on a real phone, shows every event the SDK produces, follows each one to the Edge Network, and shows what came back.

Until this is working you are not testing an implementation, you are believing one.

Connect a phone
Five minutes, and it needs the app in your hand rather than on a laptop.
1
Where Adobe Experience Platform › Assurance › Create Session
Do Create a session and choose the app. Assurance gives you a QR code and a link.
2
Do Scan the QR code with the phone running the app. The app opens and a PIN screen appears.
Note This needs a one-time deep link handler in the app. If nothing happens when you scan, that handler is missing. It is a small job for a developer rather than a fault in your setup.
3
Where Assurance › Adobe Experience Platform Edge › Event Transactions
Do Use the app while watching. Events appear as you tap[16].

The last column is the one that matters

An event visible on the client only proves the tracking code ran.

Reaching post-processed data proves the Edge accepted the payload and passed it on, which is what anybody actually meant by “is tracking working”.

Where it stops is the answer, and it tells you which team to go and talk to.

Where this goes wrong

Everything is validated on a simulator, on a debug build, in an office with good wifi. All three flatter the implementation. Install attribution behaves differently on a real install, release builds remove the logging that made debugging easy, and a queue that always drains instantly hides every question about what happens when it does not. Validate the release build on a real phone before signing anything off.

✓ Ready when

A real phone on a release build shows Launch, Close, and every event from your list reaching post-processed data, with the customer ID attached where somebody has signed in. Screenshot that view. It is the only evidence that survives the meeting.
