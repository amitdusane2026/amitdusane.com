--- title: "Deliver and maintain" seotitle: "Delivering and Maintaining Adobe Analytics" description: "The work that keeps an implementation trustworthy: designing it up front with a solution design reference, proving it works, and carrying the data forward into Customer Journey Analytics." type: category catorder: 5 ---

An implementation that works on the day it ships is not the same as one that stays trustworthy. Sites get redesigned, developers move on, and a variable quietly stops populating while the reports keep drawing a confident line.

This category is about catching that, and preventing it. It starts with the solution design reference, the document that defines what should be collected before anyone builds it. From there it covers how to verify data is arriving as intended, and how Adobe Analytics connects to Customer Journey Analytics as the platform moves forward. This is the work that decides whether the data is still believed two years from now.
