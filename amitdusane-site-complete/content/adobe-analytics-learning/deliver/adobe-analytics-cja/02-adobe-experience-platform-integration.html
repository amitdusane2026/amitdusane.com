Adobe Analytics integrates deeply with Adobe Experience Platform (AEP) for enhanced data collection, unified profiles, and advanced activation.

Integration Methods

MethodDirectionPurpose
Analytics Source ConnectorAnalytics → AEPBackfill & stream Analytics data to Platform
Web SDKWebsite → BothSingle tag sends to Analytics & AEP
Server-Side ForwardingAnalytics → AEPForward hit data to Experience Platform
Customer Journey AnalyticsAEP → CJACross-channel analysis in CJA

Benefits of AEP Integration

  • Unified data collection: Single SDK for all Adobe solutions
  • Real-time profiles: Analytics data enriches customer profiles
  • Cross-channel analysis: Combine web, app, offline data in CJA
  • Activation: Use Analytics segments in RTCDP for personalization
  • Future-proof: Web SDK is Adobe's strategic collection method
Pro Tip

If starting a new implementation, strongly consider Web SDK over AppMeasurement. It provides a unified data collection approach and prepares you for Customer Journey Analytics and other AEP capabilities.
