Customer Journey Analytics is where Adobe is taking analytics. This module is not a course in using it. It is an honest comparison for somebody who already knows Adobe Analytics well.

It starts with the one architectural difference everything else follows from. Adobe Analytics decides at collection and stores the answer; CJA stores the event and decides when you run the report. From there it covers what each product has that the other does not, which long standing Adobe Analytics restrictions CJA actually removes, and what a migration involves. There is no deadline, which should change how you decide.
