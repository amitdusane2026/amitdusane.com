Real-Time Configuration

Recommended Setup for Testing
Report 1: Page Views
├── Primary Dimension: Page
├── Secondary: None
└── Use: Verify pageName values

Report 2: Custom Variables
├── Primary Dimension: eVar (your test eVar)
├── Secondary: Page
└── Use: Validate eVar values

Report 3: Events
├── Primary Dimension: Page
├── Metric: Your test event
└── Use: Confirm events fire

Pro Tips:
- Use "Referencing Page" to see entry points
- Add secondary dimensions for context
- Filter to your IP for isolated testing
