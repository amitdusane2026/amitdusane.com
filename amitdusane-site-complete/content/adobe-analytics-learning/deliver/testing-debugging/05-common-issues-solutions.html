Products String Validation

Common Products String Errors
Correct Format:
Category;Product;Quantity;Price;Events;Merchandising

Example:
"Shoes;SKU123;1;99.99;event1=1;eVar10=red"

Common Errors:
✗ Missing semicolons: "ShoesSKU12319999"
✗ Wrong order: "SKU123;Shoes;99.99;1"
✗ Spaces in values: "Shoes; SKU123; 1; 99.99"
✗ Currency symbols: "Shoes;SKU123;1;$99.99"
✗ Comma decimals: "Shoes;SKU123;1;99,99"

Validation Tips:
- Always 6 fields (use empty semicolons if needed)
- Numeric fields: no currency symbols or commas
- Multiple products: separate with comma
- Test with simple values first
Pro Tip

Create a QA spreadsheet that lists every variable, its expected value, and where it should appear. Work through this systematically when validating implementations to ensure nothing is missed.
