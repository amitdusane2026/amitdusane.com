The AEP Debugger is the primary tool for inspecting Adobe Experience Cloud implementations, including Analytics, Target, and Launch.

Key Features

  • Summary view: Quick overview of all Adobe solutions on page
  • Analytics inspection: View all variables sent in each request
  • Launch validation: Check rules fired, data elements, extensions
  • Network requests: See actual beacon calls to Adobe
  • Experience Cloud ID: Verify visitor identification
  • Logs: Console-style logging of tag activity

Analytics Tab Details

What to Inspect
Report Suite ID (rsid)
├── Verify correct report suite
└── Check for multi-suite tagging

Page Variables
├── pageName - Is it populated correctly?
├── channel - Site section accurate?
├── hier1-5 - Hierarchy values
└── server - Server/domain

Custom Variables
├── eVar1-250 - Conversion variables
├── prop1-75 - Traffic variables
├── list1-3 - List variables
└── products - Product string format

Events
├── events - Which events fired?
├── purchaseID - Deduplication ID
└── currencyCode - Currency setting

Visitor Info
├── Experience Cloud ID (mid)
├── Analytics Visitor ID (aid)
└── Customer ID (if set)
💡 Pro Tip

Use the "Lock" feature in the debugger to keep inspecting a specific page even as you navigate. This is invaluable for debugging multi-page flows like checkout processes.
