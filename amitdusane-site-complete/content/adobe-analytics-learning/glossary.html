--- title: "Adobe Analytics Glossary" description: "Plain-language definitions of Adobe Analytics terms: props, eVars, events, dimensions, metrics, segments, and the rest of the vocabulary." seotitle: "Adobe Analytics Glossary of Terms" type: glossary weight: 999 ---

A comprehensive reference of key terms and concepts used throughout Adobe Analytics. Use this glossary as a quick lookup while learning or working with the platform.

A

Activity Map
A browser-based tool that displays visual overlays on web pages showing link click activity with color-coded rankings.
Allocation
The setting that determines how an eVar assigns credit when multiple values are set. Options include Most Recent, Original, or Linear.
Analysis Workspace
Adobe Analytics' primary reporting interface featuring drag-and-drop panels, visualizations, and freeform tables for flexible data analysis.
Anomaly Detection
Machine learning feature that automatically identifies statistically significant deviations from expected metric values.
AppMeasurement
Adobe's traditional JavaScript library (AppMeasurement.js) for collecting analytics data and sending it to Adobe servers.
Attribution
The process of assigning credit for conversions to marketing touchpoints. Attribution IQ provides multiple models for analysis.

B

Beacon
The HTTP request sent to Adobe servers containing analytics data. Also called an image request or server call.
Bounce
A visit consisting of only a single page view, where the visitor left without any additional interaction.
Bounce Rate
The percentage of visits that are bounces. Calculated as: Bounces ÷ Entries × 100.
Bot Filtering
The process of identifying and excluding non-human traffic (crawlers, spiders, bots) from analytics data.

C

Calculated Metric
A custom metric created by combining existing metrics using mathematical formulas, functions, and segments.
Campaign Variable
A reserved variable (s.campaign) used to track marketing campaign tracking codes, typically populated via URL parameter.
Classification
Metadata added to dimension values post-collection, allowing grouping of granular values into categories without changing implementation.
Context Data
Flexible key-value pairs (s.contextData) sent with hits that can be mapped to variables via Processing Rules.
Conversion Variable
See eVar. Variables designed to persist beyond the initial hit and associate with subsequent conversion events.
Cross-Device Analytics (CDA)
Feature that stitches visitor data across devices to provide a unified view of the customer journey.
Customer Journey Analytics (CJA)
Adobe's next-generation analytics product built on Experience Platform, enabling cross-channel analysis.

D

Data Element
In Adobe Launch, a reusable reference to data (from data layer, DOM, cookies, etc.) used across rules and extensions.
Data Feed
Raw, hit-level data export delivered automatically to FTP or cloud storage, containing every collected variable.
Data Layer
A JavaScript object on a web page containing structured data for analytics and marketing tools to consume.
Data Warehouse
Tool for extracting large volumes of unsampled, aggregated data with flexible dimensions and delivery options.
Datastream
Configuration in Adobe Experience Platform that routes data from Web SDK to various Adobe solutions.
Dimension
An attribute or characteristic used to categorize data. Examples: Page Name, Browser, Campaign.

E

ECID (Experience Cloud ID)
A universal visitor identifier used across Adobe Experience Cloud solutions for cross-solution visitor recognition.
Entry
The first page or value in a visit. Entry Pages show where visitors begin their sessions.
eVar (Conversion Variable)
Custom variables (eVar1-eVar250) with configurable persistence, used to track values that should be associated with later conversions.
Event
A metric that counts or captures values when specific actions occur. Types include Counter, Numeric, and Currency events.
Event Serialization
A deduplication method using unique IDs to prevent the same event from being counted multiple times.
Exit
The last page or value in a visit. Exit Pages show where visitors end their sessions.
Expiration
The setting that determines how long an eVar value persists. Options include Hit, Visit, or custom timeframes.

F

Fallout
A visualization showing conversion rates between defined touchpoints in a sequence, revealing where users drop off.
First Touch
Attribution model that gives 100% credit to the first touchpoint in a visitor's journey.
Flow
A visualization showing paths visitors take through your site, displaying previous and next values for any dimension.
Freeform Table
The primary data table in Analysis Workspace allowing flexible combinations of dimensions, metrics, and segments.

G-H

Global Report Suite
A report suite that collects data from all properties/sites, enabling organization-wide analysis.
Hierarchy Variable (hier)
Variables (hier1-hier5) used to capture hierarchical site structure, with levels separated by delimiters.
Hit
A single request sent to Adobe servers. Types include page views (s.t()) and link tracking calls (s.tl()).

I-L

Instance
A metric counting times a variable was explicitly set on a hit. Different from Occurrences for persisted eVars.
Last Touch
Attribution model that gives 100% credit to the most recent touchpoint before conversion.
Launch (Adobe Experience Platform Tags)
Adobe's tag management system for deploying and managing marketing and analytics tags on websites.
Linear Attribution
Attribution model that distributes credit equally across all touchpoints in the conversion path.
Link Tracking
Tracking method (s.tl()) for capturing interactions without a full page load, like clicks, downloads, or video plays.
List Variable (list)
Variables (list1-list3) that accept multiple delimited values in a single hit, each receiving full credit.
Lookback Window
The time period considered when applying attribution models. Can be set to Visit, Visitor, or custom timeframes.

M

Marketing Channel
A categorization of traffic sources (Paid Search, Email, Direct, etc.) configured via Marketing Channel Processing Rules.
Merchandising eVar
eVar configuration that binds values to specific products, enabling product-level analysis of attributes like color or size.
Metric
A quantitative measurement. Examples: Page Views, Visits, Revenue, Conversion Rate.
Multi-Suite Tagging
Sending the same hit to multiple report suites simultaneously using comma-separated RSIDs.

O-P

Occurrence
A metric counting all hits where a variable has a value, including persisted values from previous hits.
Page View
A hit generated by calling s.t() or equivalent, typically representing a full page load.
Participation
Attribution model giving 100% credit to every touchpoint that participated in the conversion path.
Pathing
Analysis of the sequence in which visitors navigate through pages or values. Enabled on props.
Processing Rules
Self-service rules in the Admin Console that transform incoming data before storage (e.g., mapping context data to variables).
Products String
A specially formatted variable (s.products) containing product data: Category;Product;Quantity;Price;Events;Merchandising.
Prop (Traffic Variable)
Custom variables (prop1-prop75) that do not persist beyond the hit. Used for pathing and hit-level analysis.

R

Real-Time Reports
Reports showing data within seconds of collection, used for validating implementations and monitoring live activity.
Report Suite
A data repository in Adobe Analytics that stores all collected data for a defined scope (site, app, region, etc.).
RSID (Report Suite ID)
The unique identifier for a report suite, used to direct data collection to the correct destination.

S

s Object
The main AppMeasurement JavaScript object containing configuration, variables, and tracking methods.
s.t()
The AppMeasurement method that sends a page view tracking call to Adobe servers.
s.tl()
The AppMeasurement method that sends a link tracking call for interactions without page loads.
Segment
A filter that isolates subsets of data based on defined criteria, using containers (Hit, Visit, Visitor) and logic operators.
Sequential Segment
A segment with conditions that must occur in a specific order, using THEN operators for path-based analysis.
Server Call
Any hit sent to Adobe servers. Organizations are allocated a certain number based on their contract.
Solution Design Reference (SDR)
Documentation mapping every variable to its business purpose, expected values, and implementation details.
Success Event
See Event. Custom metrics that track business-significant actions like purchases, sign-ups, or video completions.

T-U

Time Decay
Attribution model giving more credit to touchpoints closer in time to the conversion.
Tracking Server
The domain where analytics data is sent. Can be Adobe's domain or a CNAME configured for first-party collection.
Traffic Variable
See Prop. Hit-scoped variables used for pathing analysis and traffic reporting.
Unique Visitors
The count of distinct individuals visiting your site, identified by cookies or other visitor ID methods.

V-W

Virtual Report Suite (VRS)
A filtered view of a parent report suite that applies segments at report time without duplicating data.
Visit
A session consisting of consecutive hits from a visitor. Ends after 30 minutes of inactivity or at midnight.
Visitor
A unique individual identified across visits, typically via browser cookies containing the visitor ID.
VISTA Rules
Server-side processing rules implemented by Adobe Engineering for complex data transformations beyond Processing Rules capabilities.
Web SDK
Adobe's modern JavaScript library (alloy.js) for sending data to Experience Platform Edge Network and multiple solutions.
