Nothing exists in Adobe Analytics until something on a page or in an app sends it there. This category is about that journey: the libraries that do the sending, the tag manager that decides when they fire, and the tracking calls that carry the payload.

The order matters. Collection methods come first, because they frame the choice between AppMeasurement and the Web SDK. The data layer follows, since it is the structured source most implementations read from. Tags come next, because a tag manager is how those values actually get deployed. Tracking calls come last, once there is somewhere for them to fire from.
