Adobe Launch is how tags reach a website without a developer release for every change. That is the whole promise, and it is why nearly every implementation runs through it.

This module covers how Launch is assembled: properties, extensions, data elements and rules. It covers the publishing workflow and the environments that keep a mistake away from production. And it covers consent, because a tag that fires before somebody has agreed to it is a problem that no report will ever show you.
