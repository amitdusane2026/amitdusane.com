Adobe Analytics can only report what a tracking call carried. If your campaign codes arrived as a string of letters and numbers, that string is what the report shows, and nobody wants to read it.

Classifications fix that. You upload a file mapping each collected value to the attributes you actually wanted, and the reports change retroactively without anyone touching code. This module covers designing the key, which decides whether any of it works, then building sets, importing files, and writing rules that fill the columns for you. It ends with maintenance, because a broken classification does not produce an error. It produces a confident, well formatted, wrong report.
