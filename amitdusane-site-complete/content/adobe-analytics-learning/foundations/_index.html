--- title: "Start with the foundations" seotitle: "Adobe Analytics Foundations" description: "What Adobe Analytics is, where its data lands, and which variables carry that data. These are the decisions that are hardest to reverse later." type: category catorder: 1 ---

Nobody starts here because it is exciting. They start here because of what happens when it is skipped.

An implementation can run for years without these decisions being made properly, and still fail the first hard question somebody asks of it. By then the report suite holds three years of data, and the variable everybody depends on was never set to persist. This phase is short, and it covers the choices that cost the most to reverse. Almost everything else can be corrected later.
