Props, eVars and events are the containers your data travels in. Almost every reporting frustration traces back to a value sitting in the wrong one.

This module covers what each is genuinely for, and the properties that catch people out. eVar persistence, which decides who gets credit for a sale long after the visit that earned it. The products string, which runs an entire ecommerce funnel through a single line of text. And context data, which lets you send values without spending a variable slot at all. It ends with planning, because the reliable way to choose variables is to start from the report you want and work backwards.
