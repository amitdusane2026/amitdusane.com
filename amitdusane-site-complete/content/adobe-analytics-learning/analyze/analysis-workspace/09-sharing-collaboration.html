Curation

Curating a project creates a simplified view by hiding components not relevant to the audience.

  • Hide unused dimensions, metrics, and segments from left rail
  • Pre-apply segments that shouldn't be changed
  • Lock date ranges for consistent reporting
  • Add descriptions to guide users
⚠️ Sharing Permissions
  • Can Edit: Full access to modify the project
  • Can Duplicate: Can save their own copy, not edit original
  • Can View: Read-only access, no saving

Scheduled Reports

Scheduling Best Practices
1. Use relative date ranges ("Last 7 Days" not fixed dates)
2. Set expiration dates to avoid orphaned schedules
3. Include project description in email body
4. Test PDF rendering before scheduling
5. Consider timezone for global teams
6. Limit recipients to those who need it (avoid report fatigue)
