Visualizations transform data into charts, graphs, and other visual formats for easier interpretation.

Common Visualizations

VisualizationBest ForData Requirements
LineTrends over timeTime dimension + metric(s)
BarComparing categoriesDimension + metric
DonutPart-to-wholeDimension + metric (few items)
Freeform TableDetailed dataAny dimensions + metrics
Summary NumberKPI displaySingle metric
FlowPath analysisDimension (pages, events)
FalloutFunnel analysisTouchpoints (pages, events)
CohortRetention analysisInclusion + return criteria
MapGeographic dataGeo dimension + metric
HistogramDistributionMetric only
VennSegment overlap2-3 segments
ScatterCorrelation2 metrics
ℹ️ Linked Visualizations

When you create a visualization from a freeform table, they become linked. Changes to the table automatically update the visualization. Right-click to unlink if needed.
