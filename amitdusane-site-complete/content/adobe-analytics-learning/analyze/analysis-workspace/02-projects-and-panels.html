Panels are containers that hold visualizations and tables. Each panel can have its own date range and segments.

Panel Types

PanelPurposeKey Features
Blank PanelCustom analysisStart from scratch, full flexibility
FreeformGeneral analysisTables and visualizations
AttributionAttribution modelingCompare models, conversion analysis
Quick InsightsFast answersGuided analysis for beginners
Segment ComparisonCompare audiencesStatistical significance testing
Media Concurrent ViewersStreaming analysisPeak concurrency, time-spent

Panel Settings

  • Date range: Each panel can have independent date ranges
  • Segments: Apply segments at panel level (affects all content)
  • Report suite: Change report suite per panel
  • Collapse/Expand: Manage screen space with large projects
💡 Pro Tip

Use multiple panels to compare time periods side-by-side. Set Panel 1 to "This Month" and Panel 2 to "Last Month" with the same visualizations for easy comparison.
