Freeform tables are the foundation of Analysis Workspace, providing flexible, pivot-table-like analysis capabilities.

Table Building Basics

  • Rows: Drag dimensions to add breakdown categories
  • Columns: Drag metrics to add measurements
  • Breakdown: Drag dimension onto a row to break it down further
  • Segments: Drop segments on rows or columns to filter
  • Date ranges: Apply different date ranges to columns

Table Features

FeatureHow to AccessPurpose
Column SettingsClick column header gearWrap text, show totals, format
Row SettingsRight-click rowBreakdown, create segment, exclude
Conditional FormattingColumn settingsColor-code values
TotalsTable settingsShow/hide grand total, subtotals
Static RowRight-click rowLock row position regardless of sort
PaginationTable bottomControl rows shown (default 400)
