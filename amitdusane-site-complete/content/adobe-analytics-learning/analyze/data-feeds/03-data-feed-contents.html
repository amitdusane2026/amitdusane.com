Data Feed deliveries contain multiple files that work together to provide complete hit-level data.

File Structure

FileFormatContents
hit_data.tsvTab-delimitedActual hit data with all columns
column_headers.tsvTab-delimitedColumn names matching data file
manifest.txtTextFile list and row counts
Lookup filesTab-delimitedID-to-name mappings

Key Lookup Files

Common Lookup Files
browser.tsv          → Browser ID to name
browser_type.tsv     → Browser type ID to name
color_depth.tsv      → Color depth ID to value
connection_type.tsv  → Connection type ID to name
country.tsv          → Country ID to name
javascript_version.tsv → JS version ID to version
languages.tsv        → Language ID to name
operating_systems.tsv → OS ID to name
plugins.tsv          → Plugin ID to name
resolution.tsv       → Resolution ID to dimensions
search_engines.tsv   → Search engine ID to name
event.tsv            → Event ID to event name (custom)

Important Columns

ColumnDescription
hit_time_gmtUnix timestamp of hit
visid_high / visid_lowVisitor ID components
visit_numVisit number for this visitor
visit_page_numPage number within visit
post_* columnsProcessed values (use these)
pre_* columnsRaw values before processing
exclude_hitBot filtering flag
post_product_listProducts string (parsed format)
Pre vs Post Columns

Always use post_ columns for analysis. These contain values after processing rules, VISTA rules, and bot filtering have been applied. Pre_ columns show raw, unprocessed values.
