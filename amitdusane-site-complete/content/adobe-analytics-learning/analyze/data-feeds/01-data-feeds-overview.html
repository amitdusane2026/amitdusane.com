Data Feeds provide raw, hit-level data exported from Adobe Analytics. Unlike Data Warehouse which aggregates data, Data Feeds deliver every single hit with all associated variables.

Key Characteristics

  • Hit-level granularity: Every page view, click, and event as individual rows
  • Complete data: All variables collected, including those not in UI
  • Automated delivery: Scheduled exports to FTP, SFTP, or cloud storage
  • Hourly or daily: Choose delivery frequency based on needs
  • Historical backfill: Request past data when setting up new feeds
