Delivery Intervals

IntervalDelivery TimeBest For
Hourly~2 hours after hour endsNear real-time pipelines, streaming
Daily~2-4 hours after day endsStandard ETL, daily reporting

Destination Options

  • FTP/SFTP: Traditional file transfer to your servers
  • Amazon S3: Direct delivery to AWS buckets
  • Google Cloud Platform: Delivery to GCS buckets
  • Azure Blob Storage: Delivery to Azure containers
ℹ️ Multiple Feeds

You can create multiple feeds for the same report suite with different configurations - for example, one hourly feed for real-time dashboards and one daily feed for your data warehouse.
