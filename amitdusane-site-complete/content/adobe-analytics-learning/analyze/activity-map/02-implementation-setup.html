Activity Map requires enabling the module in your implementation and installing the browser extension.

Implementation Requirements

MethodRequirement
AppMeasurementActivity Map module enabled (included by default in recent versions)
Web SDKclickCollectionEnabled: true in configuration
Adobe LaunchEnable "Link Tracking" in Adobe Analytics extension

Browser Extension

  • Chrome: Install from Chrome Web Store
  • Firefox: Install from Firefox Add-ons
  • Edge: Install from Microsoft Edge Add-ons

AppMeasurement Configuration

JavaScript
// Activity Map is enabled by default in AppMeasurement 2.x
// To explicitly enable or configure:

s.ActivityMap = {
    // Link tracking settings
    linkExclusions: '',      // CSS selectors to exclude
    regionExclusions: '',    // Regions to exclude
    linkMethod: 's_objectID' // Method to identify links
};

// For custom link identification, use s_objectID
<a href="page.html" id="nav-link" 
   onclick="s_objectID='custom_link_name';">Click Here</a>
ℹ️ Permissions Required

Users need the "Activity Map" permission in Adobe Analytics to use the tool. Admins can grant this via Admin Console → User Management → Permission Groups.
