Once installed, Activity Map provides several views and tools for analyzing link clicks.

Main Views

ViewDescriptionUse Case
Overlay ModeBubbles displayed on page linksVisual click analysis
Bubble ModeGradient bubbles showing rankQuick identification of popular links
Gainer/LoserLinks with biggest changesTrend identification
Top LinksRanked list of all linksDetailed link comparison
Page DetailsPage-level metricsOverall page performance

Metrics Available

  • Link Clicks: Total clicks on each link
  • Link Clicks %: Percentage of total page clicks
  • Region Clicks: Clicks within page regions
  • Link Rank: Position relative to other links
  • Time on Page: Average time spent (page details)

Filtering Options

Activity Map Filters
Date Ranges:
├── Real-time (last 15 min)
├── Today
├── Yesterday
├── Last 7 days
├── Last 14 days
└── Last 30 days

Segments:
├── Apply any Adobe Analytics segment
├── Filter to specific visitor groups
└── Compare segment behavior

Metrics:
├── Link Clicks (default)
├── Page Views
├── Time Spent
└── Custom events (if configured)
Pro Tip

Use the "Compare" feature to see how link clicks changed between two time periods. This is invaluable for measuring the impact of page redesigns or A/B tests.
