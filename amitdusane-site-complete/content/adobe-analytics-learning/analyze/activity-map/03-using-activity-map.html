There are two quite different experiences of Activity Map, and people tend to know only one of them.

The first is the overlay. You install a browser extension, open your own website, switch it on, and numbers appear on top of the page you are looking at. It is immediate, it needs no report building, and it is the version everybody demonstrates.

The second is four dimensions in a components list. It looks like nothing at all and it is where the actual analysis happens.

Two ways to look at the same four dimensions

Both views read the same data. Nothing is collected for one and not the other. The difference is entirely in what each one lets you ask.

Reading that table, the division of labour is obvious. Use the overlay to show somebody something. Use Workspace to decide anything.

The overlay, and what Live mode cannot do

The overlay runs as a browser extension in Chrome, Edge or Firefox. It needs the Activity Map tool permission and access to the dimensions, both granted per product profile, so it is common for an analyst to have Workspace access and no overlay.

Once running, it draws each tracked link's activity onto the page as you browse it, so you see the ranking in place rather than as a list of names you have to picture.

That in-place quality is the whole value, and it is genuinely persuasive in a room. A designer arguing that the hero button is the important one can be shown, on their own page, that the third item in the navigation gets four times the clicks. No table achieves that in the same number of seconds.

Live mode has real limits, and they are the reason it cannot be your analysis tool. Segments do not work in it, so you cannot look at one audience. It does not work with virtual report suites, so if your reporting is built on one, the overlay is showing you a different population from your dashboards. And some links are not ranked at all, typically ones inside menus that are hidden until you interact with them.

The overlay shows the page as it is now, and the data as it was

This catches people after a redesign. The overlay draws numbers onto whatever page is currently in your browser, using data collected over the period you selected. If the page changed last week, you are looking at old click data positioned on a new layout, and elements that did not exist then simply have nothing. It is not wrong, but it invites a wrong reading, because everything on screen looks like it belongs together. After any redesign, either shorten the date range to the period since launch or accept that you are comparing two different pages.

Link by Region is the one people miss

Three of the four dimensions are self-explanatory. The fourth is the one that answers the questions people actually have.

Activity Map Link on its own tells you a link called Contact us was clicked 30,000 times. That link is in the header, in the footer, and on the support page, and the dimension has merged all three.

Activity Map Link By Region keeps them apart, because it combines the link name with the region it sat in. Now you can see that the footer version gets almost everything and the header version is barely used, which is an actual finding somebody can act on.

Link merges the same name. Link By Region keeps it apart.

Any time a link appears in more than one place, and most navigation does, this is the dimension to reach for. It is also the one that makes a good region setup pay off, which is the argument for fixing region names when they are generated nonsense.

Clicks are popularity, not value

The most common mistake with this data is treating the ranked list as a ranking of importance.

A link near the top of a page, in the navigation, or repeated on every template will collect enormous numbers because of where it is. That tells you about placement. It says nothing about whether the people who clicked it went on to do anything worth doing.

The correction is one column. Put a conversion metric beside occurrences and the list usually reorders. A link with a tenth of the clicks and five times the order rate is the more valuable element, and it is invisible in the overlay, which only knows about clicks.

This is the single strongest argument for working in Workspace rather than on the page. The overlay can show what is popular. Only a report can show what works.

Follow along: read one page both ways

Half an hour, and the point is to feel the difference rather than to produce anything.

Do this The same page, on the page and in a table
  1. Part one, on the page
  2. Install the Activity Map extension, sign in, and open a page you know well on your own site. If the extension shows nothing, check the tool permission before assuming the data is missing.
  3. Set a sensible date range and read the ranking in place. Note the top three elements. Note anything that surprises you, because that is the finding.
  4. Try to view it for one audience, for example new visitors only. You cannot. This is Live mode's limit and the reason for part two.
  5. Part two, in a table
  6. In Workspace, put Activity Map Page in rows, find that page, and break it down by Activity Map Link By Region. Use Link By Region rather than Link, so repeated navigation items stay separate.
  7. Add a conversion metric beside occurrences. Compare the two orderings. Where they disagree is where the interesting conversation is.
  8. Apply the segment you could not apply in the overlay. New against returning usually moves the ranking more than people expect.
  9. Trend the top element over the last quarter. If something was redesigned in that period, you should be able to see it.

There is nothing to configure. The overlay for showing, the table for deciding, and the same four dimensions underneath both.

Show the overlay, decide in the report

The overlay and the four dimensions read the same data and suit different jobs. The overlay puts numbers on a real page, which is unbeatable for showing somebody something they did not believe. It cannot segment, it does not work with virtual report suites, it cannot trend, and it knows nothing about conversion.

Workspace does all of those and looks like nothing. That is where the analysis belongs.

Reach for Link By Region whenever a link appears in more than one place, which is most navigation, because plain Link merges them and hides the answer. And put a conversion metric next to the click count every time, because a ranked list of clicks is a ranking of placement rather than of value.

What remains is the judgment around all of it: which questions this data answers honestly, where it quietly misleads, and what a single page application does to it. Activity Map Best Practices covers those, including the one structural problem that has no clean fix.

Where to find it in Adobe Analytics

The four dimensions are in the components list in Analytics > Workspace. Search for Activity Map and all four appear together.

The overlay is a browser extension for Chrome, Edge or Firefox, installed from the browser's own extension store and signed in with your Adobe credentials. It requires the Analytics Tools > Activity Map permission and access to the Activity Map dimensions, both set per product profile in the Admin Console.
