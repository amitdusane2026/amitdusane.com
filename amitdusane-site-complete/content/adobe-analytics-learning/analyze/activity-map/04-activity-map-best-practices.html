Get the most out of Activity Map with these tips and solutions to common issues.

Best Practices

  • Use s_objectID: Implement custom link IDs for consistent tracking
  • Define regions: Use HTML5 landmarks or data attributes for region tracking
  • Exclude navigation: Filter out persistent nav links to focus on content
  • Combine with Workspace: Export data for deeper analysis
  • Regular reviews: Check Activity Map monthly for UX insights

Link Identification Hierarchy

How Activity Map Identifies Links
Activity Map uses this priority order to name links:

1. s_objectID (if set via onclick)
2. Link text content
3. Alt text (for image links)
4. Title attribute
5. href attribute (fallback)

Best Practice: Always use s_objectID for:
- Links with identical text ("Learn More", "Click Here")
- Dynamic/JavaScript links
- Image-only links
- Links that change frequently
⚠️ Privacy Considerations

Activity Map tracks link clicks which may include personally identifiable information if links contain user data. Review your implementation to ensure PII is not captured in link tracking.
