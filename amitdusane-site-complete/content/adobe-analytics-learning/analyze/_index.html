--- title: "Analyze the data" seotitle: "Analyzing Data in Adobe Analytics" description: "Turning collected data into answers: calculated metrics, segments, Analysis Workspace, attribution, and the exports for questions the interface cannot answer." type: category catorder: 4 ---

Collected and shaped data still answers nothing until someone asks it a question. This category is about asking well: slicing the audience that matters, building the analysis that shows it, and knowing which tool to reach for when a question outgrows the interface.

It opens with calculated metrics, because a well-built metric is what most real questions are measured against. Segments follow, since almost every question narrows to which people. Analysis Workspace is where both get applied, then attribution explains which touchpoints earned the credit. Data Warehouse and Data Feeds cover the questions the interface cannot answer, and Activity Map covers what people click.
