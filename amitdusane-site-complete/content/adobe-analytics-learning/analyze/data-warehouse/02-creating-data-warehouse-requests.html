Data Warehouse requests are built by selecting dimensions, metrics, segments, and date ranges, then choosing a delivery method.

Request Components

ComponentDescriptionLimits
Date RangeTime period for data extractionUp to 36 months historical
DimensionsBreakdown attributesMultiple levels supported
MetricsQuantitative measurementsMost standard + custom events
SegmentsFilter data subsetMust be DW-compatible
GranularityTime breakdown levelHour, Day, Week, Month, Year

Building a Request

Example Request Structure
Request Name: Monthly Campaign Performance Export

Date Range: Last Month
Granularity: Day

Dimensions (Rows):
├── Marketing Channel
├── Tracking Code
└── Device Type

Metrics (Columns):
├── Visits
├── Orders
├── Revenue
└── Units

Segment: Purchasers Only

Delivery: SFTP to data-warehouse.company.com
Format: CSV
Schedule: Monthly on 3rd day
Segment Compatibility

Not all segments work in Data Warehouse. Segments using sequential logic, certain dimensions (like time-based), or hit containers with visit/visitor metrics may be incompatible. Check the compatibility icon in the segment builder.
