Analysis Workspace has limits. Low Traffic buckets away values you never got to see, and long lists get truncated. Data Warehouse does neither.

This module covers what it is for, how to write a request when you are describing a table you will not see for hours to a system that asks no questions, and where the finished file ends up. It also covers when not to use it, because a Data Warehouse request is a slow way to answer a question Workspace would have answered in ten seconds.
