Data Warehouse is Adobe Analytics' tool for extracting raw, unsampled data in bulk. It's designed for large-scale data exports and complex queries that aren't possible in standard reporting interfaces.

Key Characteristics

  • Unsampled data: Always returns 100% of data, never sampled
  • Bulk export: Handle millions of rows in a single request
  • Flexible delivery: Email, FTP, SFTP, cloud storage destinations
  • Scheduled reports: Automate recurring data extracts
  • Extended breakdowns: More breakdown levels than Workspace
  • Historical data: Access data going back to implementation start
📊 Data Warehouse vs Workspace
Workspace
Interactive • Visual • May sample • Fast
vs
Data Warehouse
Bulk export • Raw data • Unsampled • Queued
