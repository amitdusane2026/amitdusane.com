Data Warehouse supports multiple delivery destinations for flexibility in data workflows.

Delivery Methods

MethodBest ForConfiguration
EmailSmall files, ad-hoc requestsEmail address, file size limit ~10MB
FTPLegacy systemsHost, port, credentials, path
SFTPSecure transfersHost, port, credentials, SSH key
Amazon S3AWS data pipelinesBucket, region, access keys
Google CloudGCP data pipelinesBucket, service account
Azure BlobAzure data pipelinesContainer, SAS token

File Formats

  • CSV: Comma-separated, universal compatibility
  • TSV: Tab-separated, handles commas in data

Scheduling Options

Schedule Configurations
One-time: Run once immediately or at scheduled time

Recurring Options:
├── Hourly: Every X hours
├── Daily: Every X days at specific time
├── Weekly: Specific day(s) of week
├── Monthly: Specific day of month
└── Yearly: Specific date annually

Advanced:
├── Start/End dates for schedule
├── Delivery window preferences
└── Failure notification emails
💡 Pro Tip

For daily reports, schedule delivery for early morning (e.g., 6 AM) to ensure previous day's data is fully processed. Adobe Analytics data processing typically completes by 2-4 AM.
