Calculated metrics allow you to create custom metrics using mathematical formulas, combining existing metrics into new insights.

Building Calculated Metrics

  • Basic math: Add, subtract, multiply, divide metrics
  • Functions: Use statistical and advanced functions
  • Segments: Apply segments within the formula
  • Nesting: Use calculated metrics within other calculated metrics

Common Calculated Metrics

MetricFormulaPurpose
Conversion RateOrders / VisitsPurchase efficiency
Average Order ValueRevenue / OrdersOrder size
Bounce RateBounces / EntriesEngagement quality
Pages per VisitPage Views / VisitsDepth of engagement
Revenue per VisitorRevenue / Unique VisitorsVisitor value
Cart Abandonment Rate1 - (Orders / Carts)Checkout friction

Advanced Functions

Calculated Metric Examples
// Segmented Metric: Mobile Conversion Rate
Orders (where Mobile Visitors segment) / Visits (where Mobile Visitors segment)

// Statistical Function: Revenue Z-Score
(Revenue - Mean(Revenue)) / Standard Deviation(Revenue)

// Approximate Count Distinct (cardinality)
Approximate Count Distinct (User ID)

// Cumulative Sum
Cumulative(Revenue)

// Percentile
Percentile(Revenue, 90)  // 90th percentile
💡 Pro Tip

Add "polarity" to your calculated metrics (green = good, red = bad) to help users quickly understand if a value is positive or negative for the business.
