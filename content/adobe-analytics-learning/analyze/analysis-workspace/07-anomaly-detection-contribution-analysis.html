Adobe Analytics uses machine learning to automatically detect unusual patterns in your data and identify factors contributing to anomalies.

Anomaly Detection

  • Automatic: Runs on any trended metric in Workspace
  • Statistical model: Uses historical data to predict expected values
  • Confidence bounds: Shows upper and lower expected ranges
  • Visual indicators: Dots highlight statistically significant deviations

How to Use Anomaly Detection

Enabling Anomaly Detection
In Analysis Workspace:
1. Create a line visualization with time dimension
2. Right-click the metric column header
3. Select "Run Anomaly Detection"

Or in Column Settings:
1. Click gear icon on metric column
2. Enable "Show Anomalies"

Configuration Options:
├── Training Period: How much history to analyze (default: 35 days)
├── Confidence: Statistical confidence level (90%, 95%, 99%)
└── Granularity: Day, Week, Month

Interpreting Results:
- Gray band = Expected range
- Point above band = Positive anomaly (spike)
- Point below band = Negative anomaly (drop)
- Larger deviation = More significant anomaly

Contribution Analysis

When an anomaly is detected, Contribution Analysis identifies which dimension values most contributed to the unusual change.

Running Contribution Analysis
1. Right-click on anomaly point in visualization
2. Select "Analyze" → "Run Contribution Analysis"
3. Select dimensions to analyze

Analysis Returns:
├── Top contributing dimension values
├── Change in metric for each value
├── Percentage contribution to anomaly
└── Statistical significance score

Example Output:
Metric: Orders (dropped 40% on Tuesday)

Top Contributors:
1. Mobile Device Type: iPhone (-35% of drop)
   → iOS app crash causing checkout failures
2. Marketing Channel: Paid Search (-25% of drop)
   → Campaign paused by mistake
3. Geography: California (-20% of drop)
   → Regional site outage
