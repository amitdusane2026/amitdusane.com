Analysis Workspace is Adobe Analytics' powerful, flexible canvas for building custom analysis projects. It's the primary interface for data exploration, visualization, and reporting.

Key Features

  • Drag-and-drop interface: Build reports without writing code
  • Flexible layouts: Arrange panels, tables, and visualizations freely
  • Real-time analysis: Data updates as you build
  • Collaboration: Share projects and curate for stakeholders
  • Advanced analytics: Attribution, anomaly detection, contribution analysis
