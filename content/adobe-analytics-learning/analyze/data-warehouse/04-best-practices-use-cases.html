Use Data Warehouse effectively by understanding its strengths and optimal use cases.

When to Use Data Warehouse

Use CaseWhy Data Warehouse
Data lake ingestionBulk export to Snowflake, BigQuery, Redshift
Finance reconciliationUnsampled revenue data for accounting
Custom attributionRaw data for external attribution models
ML/AI trainingHistorical data for model development
Compliance auditsComplete data records for regulatory needs
High-cardinality reportsProduct-level data without sampling

When NOT to Use Data Warehouse

  • Real-time analysis: Data Warehouse is queued, not instant
  • Interactive exploration: Use Workspace for ad-hoc analysis
  • Small datasets: Overkill for simple reports
  • Visualizations: DW exports raw data, not charts

Performance Tips

Optimization Guidelines
1. LIMIT DATE RANGES
   ✓ Request 1 month at a time vs. 12 months
   ✓ Use scheduling for recurring needs

2. MINIMIZE DIMENSIONS
   ✓ Only include dimensions you'll actually use
   ✓ Avoid high-cardinality dimensions when possible

3. USE SEGMENTS WISELY
   ✓ Filter at request level, not post-export
   ✓ Simpler segments process faster

4. SCHEDULE OFF-PEAK
   ✓ Avoid month-end when others request
   ✓ Early morning slots process faster

5. MONITOR QUEUE
   ✓ Check request status regularly
   ✓ Cancel stuck or unnecessary requests
⚠️ Request Limits
  • Processing time varies: minutes to hours depending on complexity
  • Large requests may be queued behind others
  • Extremely large requests (billions of rows) may timeout
  • Scheduled reports count against your organization's queue
